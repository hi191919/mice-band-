# MICE BAND: Home Before Dawn

A static site: no build step, no dependencies. `index.html` is the whole game.

## Deploy to Vercel
CLI:   cd mice-band && npx vercel --prod
Or:    push this folder to a GitHub repo, then vercel.com/new -> import the repo -> Deploy
       (Framework Preset: Other, no build command, output directory = repo root).

## iPhone
Open the site in Safari -> Share -> Add to Home Screen. It launches full screen.
